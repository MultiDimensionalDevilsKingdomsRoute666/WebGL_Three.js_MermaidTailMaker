# WebGL Three.js Mermaid Tail Maker

A fork of [Maclanahan/WebGL_Three.js_MermaidTailMaker](https://github.com/Maclanahan/WebGL_Three.js_MermaidTailMaker). It's a small project for practicing JavaScript, WebGL and the Three.js library by building a mermaid tail in 3D.

## What's inside

- `public_html/`: the web app, made up of `index.html`, `js/`, `obj/` (3D models), `img/` and `styles/`.
- `nbproject/`: NetBeans project settings.

## How to view it

Serve the `public_html/` folder with any static web server (for example, run `python3 -m http.server` inside it) and open the page in a browser. Loading the 3D models usually needs a server rather than opening the file directly.
